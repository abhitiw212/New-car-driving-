AGRA DRIVE SIMULATOR — FULL BROWSER BUILD
=============================================
A complete playable single-player browser build.

RUN:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Internet is needed once to load Three.js from its CDN.

FEATURES:
- Main menu
- 3D open-world style Agra-inspired city layout
- Highway and multiple roads
- Buildings and landmark-style dome
- Day/night cycle with street lighting
- Dynamic traffic vehicles
- Manual R/N/1-6 transmission
- Touch steering wheel, gas, brake, clutch
- Keyboard WASD/arrows
- Cockpit/chase/wide camera
- Taxi mission loop with pickup/dropoff
- Cash rewards capped at ₹1000 per ride
- Garage and persistent local save
- Paint colours
- Engine progression V6/V8/V10/V12/V16
- 3 turbo levels
- Sport mode
- Drift mode

IMPORTANT:
This is a full playable web game build, but it is not a compiled Android APK or a AAA-scale 1 GB commercial game. A true mobile AAA game requires a game-engine project, original 3D assets, audio, optimization and Android packaging.
The car is an original sports-sedan design inspired by modern performance sedans rather than an exact BMW M5 replica.
